# Smart Password Strength Checker 🔐

A robust and interactive Python command-line tool designed to evaluate the strength and security of passwords based on multiple criteria, including length, numbers, uppercase letters, and special characters.

## 🚀 Features
- **Multi-criteria Validation:** Checks for minimum length (8+ chars), numbers, uppercase characters, and special symbols (`!@#$%^&*`).
- **Scoring System:** Calculates a score out of 4 to categorize passwords into **Strong**, **Medium**, or **Weak**.
- **Instant Feedback:** Provides specific error messages indicating what is missing from the password.
- **Interactive Loop:** Allows users to test multiple passwords continuously without restarting the program.

## 🛠️ Tech Stack
- **Language:** Python 3.x
